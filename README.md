# Licenta2027-Zamurca_Denisa-Nicoleta

MentorCode

MentorCode este o platformă web educațională destinată elevilor și studenților care învață programare.
Scopul proiectului este de a oferi suport pe parcursul procesului de rezolvare a problemelor, nu doar de a verifica dacă o soluție este corectă. Platforma va încerca să ajute utilizatorul să înțeleagă cerința, să construiască o strategie de rezolvare, să scrie și să testeze codul și să înțeleagă greșelile făcute.

Funcționalități propuse:

-> trasee de învățare pentru programare, OOP, algoritmi și structuri de date;

-> probleme practice și probleme de BAC la informatică;

-> editor de cod integrat cu rularea și testarea soluțiilor;

-> tutor AI care oferă întrebări și hint-uri progresive, fără a genera imediat soluția completă;

-> funcționalități de tip Help Me Get Started pentru utilizatorii care nu știu cum să înceapă o problemă;

-> vizualizări interactive pentru algoritmi și structuri de date;

-> urmărirea progresului utilizatorului;

-> recomandarea de exerciții în funcție de dificultățile observate.
